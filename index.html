Choropleth Map

The map shows the total homeless population by state in 2013. Click a state to update the pie charts and highlight the same state in the parallel coordinates plot. Double-click the chart to reset the selection.

Pie Charts

The pie charts show the selected state's category breakdown, including chronic homelessness, unaccompanied youth, veterans, and unsheltered homelessness.

Parallel Coordinates Plot

This chart compares multiple homelessness-related variables across states. Users can brush over the lines to filter states and double-click the chart to reset the selection.

Bar Chart

This horizontal bar chart ranks the top 10 states by total homeless population in 2013. Click one bar to highlight it. Double-click to reset. California ranked first. New York ranked second.

Line Chart

From 2005 to 2013, the homeless population decreased.

Methodology

Data Source: Homelessness in USA dataset

The file “2013 US State Statistics.csv” is used for the choropleth map, pie charts, parallel coordinates plot, and horizontal bar chart.

The file “Yearly National Statistics.csv” is used for the line chart showing the overall homelessness trend from 2005 to 2013.

Python and pandas were used to preprocess the original CSV files before building the visualizations. All visualizations were created using HTML, CSS, JavaScript, and D3.js. The visualizations include interactive features such as tooltips, state selection, double-click reset, and brushing.
